# Verilog
Practicing Verilog basics.

## Environment
  • OS : Windows 11
  
  • Language : Verilog 2001 (IEEE 1364-2001)
  
  • Target Board : Xilinx Spartan 6
  
  • EDA Tool : Xilinx ISE 14.7 (running on Virtual Box)


## Directory
  • '/images' : 회로도 / FSM 상태도 / 각종 이미지 저장
  
  • '/rtl' : 합성가능한 RTL 단계 코드 저장
  
  • '/tb' : Testbench 코드 저장
